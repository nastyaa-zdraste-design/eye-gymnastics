# Гимнастика для глаз

Раз в час разворачивает поверх всех окон пятиминутную зарядку для глаз:
9 упражнений с обратным отсчётом, звуком поющей чаши и точкой, за которой
следят глаза. В конце — анекдот.

Работает в трее. Windows — сейчас, macOS — та же кодовая база (сборку делать на Mac).

## Долг глазам
Лимита на переносы нет. Но каждый перенос подряд возвращает перерыв быстрее
и делает напоминания настойчивее:

| Долг | Вернётся через | Между перерывами |
|---|---|---|
| 1 | 20 мин | тишина |
| 2 | 15 мин | из-за края экрана выглядывают глаза и следят за курсором |
| 3 | 10 мин | глаза чаще и сонные |
| 4 | 7 мин | за курсором тянутся курсоры-призраки |
| 5+ | 5 мин | дымка по краям экрана, «Отложить» — только удержанием |

Зарядка до конца или 5 минут без мыши и клавиатуры списывают долг.
Эффекты прозрачны для мыши и не забирают фокус.
**Щадящий режим** в меню трея отключает их совсем.

## Горячие клавиши в окне перерыва
- `Пробел` — следующее упражнение
- `Esc` — отложить (на долге 5+ не работает — только удержание кнопки)

## Свои тексты
Трей → «Открыть папку с текстами». Там `exercises.txt` и `jokes.txt`,
формат описан в начале каждого файла. Правки подхватываются со следующего перерыва.

## Разработка
```bash
npm install
npm start                 # обычный запуск
npm run check             # проверки логики без Electron
npx electron . --now --short   # перерыв сразу, шаги по 6 секунд
npx electron . --nag=4    # сразу долг 4 — посмотреть эффекты
npx electron . --shots    # снимки окон в папку данных/shots
npm run dist:win          # установщик Windows в dist/
```

Данные и журнал: Windows — `%APPDATA%\Гимнастика для глаз`,
macOS — `~/Library/Application Support/Гимнастика для глаз`.

## Перед публичным релизом
- **Подпись кода.** Без сертификата Windows SmartScreen пугает при установке,
  а macOS без подписи и нотаризации Apple не даст запустить приложение.
- **macOS:** собрать `npm run dist:mac` на Mac; проверить окно поверх полноэкранных приложений.
- **Здоровье:** это не медицинское изделие. При боли, вспышках, «мушках»
  или резком ухудшении зрения — к офтальмологу.
